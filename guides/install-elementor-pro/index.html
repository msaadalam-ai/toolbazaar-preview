How to install Elementor Pro on WordPress, step by step

Whether you bought a license from Elementor or ordered an activation from AI Web Tools, the first step is the same and the last check is the same.

Updated 20 October 2026 · Written by AI Web Tools · How we write guides

Short answer

To install Elementor Pro, first install the free Elementor plugin from the WordPress plugin directory, then add the Pro plugin and connect it to a Pro subscription. If you bought from Elementor, download the Pro zip from your account, upload it under Plugins › Add New › Upload Plugin, activate it and connect it on the Elementor › License screen. If you ordered from AI Web Tools, you only do the first step; we install and connect Pro through a temporary admin login, usually within about an hour during 10am–10pm PKT.

Before you start

  • A WordPress site you can log in to as an administrator, on a supported WordPress and PHP version (Elementor lists the minimums in its help centre).
  • HTTPS on the site. Not required by Elementor, but you should have it anyway.
  • A backup, or at least a host that keeps one. Installing a plugin is low-risk, but habits matter.
  • If a nulled "Pro" is already installed, delete it first. Two copies of Pro cannot be active at once, and the cracked one may have left things behind.

Step 1: install the free Elementor plugin

  1. In WordPress go to Plugins › Add New and search for "Elementor".
  2. Install "Elementor Website Builder" by Elementor.com and activate it.
  3. Skip or complete the setup wizard; nothing in it is final.

Step 2a: if you bought a license from Elementor

  1. Log in to your Elementor account and download the Elementor Pro zip file.
  2. Go to Plugins › Add New › Upload Plugin, choose the zip, install and activate.
  3. Go to Elementor › License and click Connect & Activate. Log in to your Elementor account when asked.

Step 2b: if you ordered from AI Web Tools

  1. Pay ₨799 by JazzCash, Easypaisa, Raast or bank transfer and send the screenshot on WhatsApp with your site address.
  2. Install "Temporary Login Without Password" from Plugins › Add New, create a link with the Administrator role and a one-day expiry, and send us the link.
  3. We install the Pro plugin, connect it to our subscription and send you a screenshot of the active license. You delete the temporary login afterwards.

How the activation works and what we touch is explained in the activation guide.

Step 3: check it worked

  • Elementor › License shows the license as active.
  • Templates › Theme Builder exists in the WordPress menu.
  • In the editor, the widget panel now has a Pro section with Forms, Posts, Slides and the rest.
  • Dashboard › Updates will list Pro updates when Elementor publishes them.

Step 4: first settings worth doing

  • Set global colours and fonts in Elementor › Site Settings before you build anything, so every widget inherits them.
  • If you plan to design your own header and footer, switch to a light theme such as Hello so the theme's styles do not fight yours.
  • Under Elementor › Settings › Features, leave experiments at their defaults unless a tutorial tells you otherwise.

Common mistakes

  • Installing Pro without the free plugin. Pro needs free Elementor underneath; it will tell you so.
  • Uploading a zip from a GPL or nulled site and expecting the license screen to accept it. It will not, and the copy may be unsafe. See GPL, nulled and genuine.
  • Letting the temporary login expire before sending it. Create it when you are ready to send.

Questions people ask

Still unsure? Message us on WhatsApp.

Do I need a special theme for Elementor Pro?

No. Any theme works. Elementor's own Hello theme is a light option when you use the Theme Builder for the header and footer.

Can I install Pro on localhost first?

With your own license, yes. For an AI Web Tools activation we need a site we can reach online, since we log in through a temporary link.

Will installing Pro change my existing pages?

No. Pro adds widgets and builders; your pages stay as they were until you edit them.

What if I already have a nulled Pro installed?

Delete it first, then install the genuine plugin. If the site has run a nulled copy for a while, scan it for malware.
